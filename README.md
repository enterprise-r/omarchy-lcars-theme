# LCARS for Omarchy

This theme has moved to [Dark-R](https://github.com/enterprise-r/omarchy-dark-r-theme).

```bash
omarchy theme install https://github.com/enterprise-r/omarchy-dark-r-theme
cd ~/.config/omarchy/themes/dark-r
./install.sh
```

Omarchy names the theme from the repository, so `omarchy-dark-r-theme` installs as Dark R.
